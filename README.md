# A3-Flight-Computer
Hardware and software for Anduril-3 flight computer.

## Hardware 
All hardware is designed in KiCAD. If any footprints are added create a folder with the component name in the component-library folder and export all the files to there. when importing footprints and symbols add them to the A3-Flight-Computer library in KiCAD A3 Also add any datasheet and relevent documentation to this folder. 

## Software
All software will be stored in the A3-Flight-Computer-Software. (Rest of Organization TBD)

Various resources such as application notes, various datasheets etc will be stored in the resource folder
